        ## Этап 1 завершен!
        
        На первом этапе выполнено теоретическое описание модели. Рассмотрены два случая:
        
        - **Гармонический** (линейные пружинки по закону Гука)
        - **Ангармонический** (с нелинейной поправкой) — задача Ферми-Паста-Улама
        
        Выведены уравнения движения, получено дисперсионное соотношение, описаны нормальные моды. Подготовлен численный алгоритм для следующих этапов.
        
        **Участники проекта:** Бызова М.О., Верниковская Е.А., Калашникова О.С., Богаткина А.А., Сущенко А.Н.
        
        ## Этап 2 завершен!
        
        На втором этапе разработан алгоритм решения задачи о колебаниях цепочек. Алгоритм включает семь ключевых этапов:
        
        1. **Задание параметров системы** — масса, жесткость, число частиц, начальные условия
        2. **Настройка дискретизации** — выбор временного шага с учетом устойчивости
        3. **Инициализация системы** — задание равновесных координат и начальных смещений
        4. **Численное интегрирование** — схема «чехарда» для уравнений движения
        5. **Анализ энергии по модам** — дискретное синус-преобразование
        6. **Исследование ангармонических эффектов** — задача Ферми-Паста-Улама
        7. **Визуализация результатов** — графики и анимации колебаний
        
        **Участники проекта:** Бызова М.О., Верниковская Е.А., Калашникова О.С., Богаткина А.А., Сущенко А.Н.
        
        ## Этап 3 завершен!
        На третьем этапе разработан комплекс программ на языке Julia, реализующий численное моделирование колебаний одномерных цепочек. Созданы пять программ:
        
        1. **Гармоническая цепочка (task1.jl)** — моделирование с помощью схемы «чехарда», параметры: N = 32, m = 1, k = 1, Δt = 0.01
        2. **Измерение собственных частот (task2.jl)** — определение частот нормальных мод по пересечениям нуля, сравнение с теоретическим дисперсионным соотношением (отклонение для чётных мод < 1%)
        3. **Анализ независимости нормальных мод (task3.jl)** — дискретное синус-преобразование, проверка отсутствия перетекания энергии между модами в гармоническом случае
        4. **Цепочка с чередующимися массами (task4.jl)** — моделирование бинарной структуры (mlight = 1, mheavy = 2), аналог кристалла NaCl
        5. **Ангармоническая цепочка. Задача Ферми-Паста-Улама (task5.jl)** — кубическая нелинейность (α = 0.5), наблюдение классического FPU-возврата (рекурренции энергии)
        
        **Участники проекта:** Бызова М.О., Верниковская Е.А., Калашникова О.С., Богаткина А.А., Сущенко А.Н.
        
         ## Этап 4 завершен!
        
        На четвёртом этапе представлен **полный цикл исследования** — от теории до программной реализации. Подведены итоги всего проекта.
        
        **Ключевые результаты:**
        - Подтверждено дисперсионное соотношение (отклонение для чётных мод **<1%**)
        - Верифицирована независимость нормальных мод в гармоническом приближении
        - Промоделирована цепочка с чередующимися массами (аналог NaCl)
        - Воспроизведён классический эффект **Ферми-Паста-Улама** (FPU-возврат)
        
        **Итоговые материалы:**
        - Полный отчёт (49 страниц)
        - Презентация защиты
        - Видеозапись защиты (Rutube, VK)
        - Репозиторий с кодом (GitHub, GitVerse, релиз v4.0.1)
        - Архив с пятью программами
        
        **Все этапы выполнены. Проект успешно завершён!**
        
        **Участники проекта:** Бызова М.О., Верниковская Е.А., Калашникова О.С., Богаткина А.А., Сущенко А.Н.
